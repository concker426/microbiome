二、模型架构
================================================================================

ProCyon v2 架构 (三组件):

  输入: Genus abundance profile [g1, g2, ..., gk] (V=1226, 按丰度排序)
    |
  SimpleEmb: nn.Embedding(1226, 768, padding_idx=0)
    | masked mean pool (忽略 padding tokens)
  Patient representation h ∈ R^768
    |
    +---> Classification Head: MLP(768->256->BN->ReLU->Dropout(0.3)->2)
    |       |-> P(IBD | microbiome) -> Disease / Healthy
    |
    +---> Explanation Head:
            |-> LOO Attribution: per-genus importance = prob_full - prob_without_genus
            |-> Qwen2-7B-Instruct -> Biological explanation text

关键设计决策:
  1. 无 Transformer (genus序列按丰度排序, 无sequential structure)
  2. 无 Pretraining (random init, end-to-end训练)
  3. Mean pooling (非attention pooling — 避免信息瓶颈)
  4. 双分支 (分类与解释分离, 各优化各自目标)

模型复杂度: 1.14M 参数
  - Embedding: 0.93M (1226 x 768)
  - MLP: 0.21M (768x256 + 256x2)
  对比: MGM encoder 34M, Qwen2-7B 7B

三、数据集
================================================================================

3.1 clean_2538
  - 来源: Qiita平台 (qiita.ucsd.edu)
  - 队列: AGP (American Gut Project) + FTP (Fecal Transplantation Program)
  - 训练集: 659 样本
  - 测试集: 167 样本
  - 疾病比例: 55.7% (Disease=433, Healthy=393 total)
  - 属级别词汇量: V=1226
  - 序列长度: 86 (按丰度排序的genus token序列)
  - 实际出现的独特菌属: 366
  - 平均每样本菌属数: 47.8 ± 16.2
  - 稀有菌属 (<5% prevalence): 251 (68.6%)
  - 广泛菌属 (>50% prevalence): 42 (11.5%)

3.2 merged_all
  - 来源: 5个Qiita数据源
    - qiita_1939
    - qiita_2538
    - external_ibd
    - agp_ftp
    - qiita_10283
  - 训练集: 3,350 样本
  - 测试集: 838 样本
  - 疾病比例: 50.7%
  - 序列长度: 175
  - 实际出现的独特菌属: 580
  - 注意: merged_all的train/test共享全部5个数据源, 是随机划分,
    不是leave-one-study-out. 与clean_2538有568个重叠样本ID.
    其中105个clean训练样本出现在merged测试集中 (已在transfer中去除).

3.3 数据格式
  每个样本存储为:
  - JSONL (train_nl.jsonl / test_nl.jsonl): 包含 sample_id, label, messages
  - NPY (genus_sequences.npy): token IDs, shape (N, SL)
  - NPY (genus_masks.npy): 有效位置mask, shape (N, SL)

3.4 数据预处理
  - 原始BIOM表格 -> Greengenes 13.8 taxonomy -> Genus级别聚合
  - 相对丰度 -> 按丰度排序 -> Genus名 -> Token ID映射
  - Token序列 + padding + mask

    ----------------------------------------------------------

================================================================================
五、关键实验方法
================================================================================

5.1 SimpleEmb + MLP 训练
    - 优化器: AdamW (lr=1e-3, weight_decay=1e-4)
    - 学习率调度: CosineAnnealing (T_max=50 epochs)
    - Batch size: 32
    - 类别加权损失: Disease weight = 1.5x
    - 随机种子: {42, 123, 456, 789, 1024}
    - 5-seed ensemble: 平均概率

5.2 LOO (Leave-One-Out) Attribution
    方法: 对样本中每个菌属, 计算 prob_full - prob_without_genus.
    批量实现: 计算所有leave-one-out均值, 一次前向传播.
    注意: 这不是经典SHAP (Shapley values), 是deletion-based attribution.
    论文中统一使用"LOO attribution"命名.

5.3 统计检验
    - McNemar test: 配对分类差异 (exact binomial)
    - AUC差异: paired bootstrap (10,000 resamples, 95% CI)
    - Spearman rank correlation: 跨fold genus重要性排序一致性
    - ECE: 10-bin calibration error
    - Brier Score: 概率预测质量

5.4 去重Cross-Dataset Transfer
    1. 加载clean_2538和merged_all
    2. 识别sample ID重叠 (568/826 clean样本也在merged中)
    3. 从merged_test中移除105个clean_train样本
    4. 在去重后的733样本上评估

6.1 MGM (Ning et al., 2024)
    标题: MGM as a large-scale pretrained foundation model for
          microbiome analyses in diverse contexts
    期刊: Advanced Science, 2025
    预印本: bioRxiv 2024.12.30.630825
    链接: https://www.biorxiv.org/content/10.1101/2024.12.30.630825v1
    架构: 6-layer Transformer encoder (34M params)
          + attention pooling -> 768-dim
          预训练: next-genus prediction on MicroCorpus-260K (263,302 samples)
    本论文使用: 加载预训练MGM encoder, 提取768维特征,
              训练MLP classifier (256->128) 用于公平对比
    结果: ACC=50.9%, AUC=0.4625 — 在该数据集上完全失败
    模型位置: /hd/liujx/microbiome_llm_project/saved_models/mgm_encoder_pretrained/

6.2 Waypoint/Atlas (2026)
    标题: Learning the Language of the Microbiome with Transformers
    期刊: bioRxiv, 2026
    DOI: 10.64898/2026.05.02.722381
    链接: https://www.biorxiv.org/content/10.64898/2026.05.02.722381v2
    架构: Transformer encoder variants (6M-170M params)

    标题: ProCyon: A Multimodal Foundation Model for Protein Phenotypes
    参考代码: /hd/liujx/ProCyon/ 和 /hd/liujx/ProCyon-Bind/
    架构: Protein encoder + Projection layer + LLM (Llama)

6.4 FT-Transformer (Gorishniy et al., 2022)
    标题: FT-Transformer: A Transformer for Tabular Data
    预印本: arXiv:2106.11959
    核心思想: 将每个feature作为token, 用Transformer处理表格数据
    本论文使用: 作为structural baseline (E=128, 3 layers, 4 heads, FFN=512)
    结果: ACC=91.0% — 证明无预训练的Transformer也能工作, MGM的失败
          主要来自预训练而非架构

6.5 DeepSets (Zaheer et al., 2017)
    标题: Deep Sets
    会议: NeurIPS 2017
    核心思想: 置换不变集合函数 φ(x_i)->Σ->ρ(Σ)
    本论文使用: 作为structural baseline (E=256, φ=Embedding, ρ=3-layer MLP)
    结果: ACC=91.6% — 与SimpleEmb持平, 证明Set结构是正确归纳偏置

6.6 XGBoost (Chen & Guestrin, 2016)
    标题: XGBoost: A Scalable Tree Boosting System
    会议: KDD 2016
    本论文使用参数: n_estimators=200, max_depth=6, learning_rate=0.1
    结果: ACC=92.22%, AUC=0.9679 — 最强classical baseline
    统计: 与ProCyon v2无显著差异 (McNemar p=1.000)
